# Soup Kernel Challenge

Решение для хакатона Decentrathon 6.0 (Soup Kernel Challenge). Проект направлен на оптимизацию дообучения языковых моделей с помощью кастомных Triton-кернелов для ускорения вычислений и снижения расхода памяти GPU.

## Структура репозитория
- `solution/` — папка с основным кодом:
  - `kernels.py` — реализация базовых математических операций и оптимизаций.
  - `swiglu.py` — fused SwiGLU кернел (forward/backward проходы).
  - `apply.py` — логика применения и отключения оптимизаций для модели (`apply`, `unpatch`).
- `tests/` — модульные тесты для проверки корректности работы.
- `SUBMISSION.md` — детальный отчет по решению и результатам.

## Как запустить
1. Откройте блокнот в среде Kaggle.
2. Запустите ячейки или нажмите **Run All**.
3. Для проверки тестов локально или в ноутбуке выполните:
   ```bash
   pytest tests/
